# P1 — Process Taxonomy, Annotation Feasibility, and Trace Infrastructure

P1 operationalizes the approved P0 research object: the **observable execution trajectory** around a Candidate Stop. It does not test the online PCT controller and does not make an effectiveness claim.

## P1 objective

Determine whether process failures can be represented, annotated, localized, and audited with enough clarity to justify later shadow-mode and online experiments.

## Human Gate

The software and draft research artifacts are reversible development work under A2 autonomy. The taxonomy semantics, annotation unit, verdict scale, hard/soft treatment, pilot corpus, annotation independence, and P1 completion standard are human decisions.

P1 remains open until the decisions in `governance/p1-decision-register.json` are resolved and the approved annotation pilot is completed.

## Allowed conclusion now

> A development-ready P1 annotation and trace foundation exists and passes engineering checks.

This is not evidence that the taxonomy is complete, that humans can apply it reliably, or that Process-Certified Termination improves task performance.
