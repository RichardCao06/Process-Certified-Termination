# PCT-P2-I02 — D19 v0.2 交付验证器假设错误

## 事件

D19 v0.2 本地应用在提交前被验证器阻止。验证器错误地要求历史 Provider 报告与候选 Profile 的 SHA-256 **不相等**；实际两者相等。验证器还扫描所有本地文件（包括 Git 忽略文件），并使用缺少左边界的 `sk-` 模式，因此可能把普通 `risk-...` 文本或本地忽略文件误判为仓库密钥泄漏。

## 影响

- 没有创建 Git Commit；
- 没有执行模型调用或工程 Smoke；
- 没有启动 60 条正式轨迹；
- 该错误本身不能证明仓库或 GitHub Secret 已泄漏。

## 修复

替代包 v0.2.1：

1. 校验历史报告 SHA-256 与候选 Profile 相等；
2. 只扫描 Git 跟踪文件；
3. 使用左边界感知的 Secret 模式；
4. 保留 Smoke 前新鲜 `GET /models` 绑定检查，但将其作为常规安全前置条件，而不是不存在的历史错配补救。

首次失败作为工程证据保留，不通过绕过验证来继续。
