# Claim Ladder

The project must earn each claim level in order.

| Level | Required evidence | Allowed statement | Prohibited leap |
|---|---|---|---|
| L0 Protocol | P0 human approval and reproducible governance package | “We have an approved protocol.” | Any effectiveness claim |
| L1 Information | Outcome+Process predicts adjudicated truth better than Outcome-only | “Process contains incremental information.” | Automated auditor is reliable |
| L2 Audit | Auditor meets frozen agreement thresholds on held-out labels | “A bounded class of process errors is automatable.” | All process errors are detectable |
| L3 Diagnosis | First Invalid Transition localization beats matched baselines | “Audit can produce localized diagnosis.” | Final success is improved |
| L4 Calibration | False Accept decreases and False Continue is non-inferior | “PCT improves termination calibration in the tested configuration.” | General LLM-agent claim |
| L5 Repair | Localized feedback improves repair under matched compute | “Process feedback is an effective control signal.” | Model weights or intrinsic ability improved |
| L6 System | Certified Success improves within accepted cost | “Harness-level certification improves task completion in scope.” | Cross-model/harness generality |
| L7 External | second model and second harness show compatible primary effects | “The Capability Envelope can be broadened.” | Untested tasks or high-stakes deployment are covered |

Negative or mixed findings remain valid outcomes. A lower False Accept with an unacceptable False Continue increase is “more conservative,” not “better calibrated.”
